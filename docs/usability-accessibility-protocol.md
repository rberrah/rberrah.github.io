# Usability and accessibility protocol

Automated checks do not establish learning effectiveness. Run this protocol
before describing a major learning path or laboratory as validated with users.

## Participants

Recruit at least two people from each profile for an initial formative round:

- newcomer with no pharmacometrics training;
- pharmacy, medicine or quantitative-science student;
- teacher who may reuse a chapter or laboratory;
- pharmacometrics or clinical pharmacology specialist.

Record role and prior experience only. Do not collect patient information.

## Tasks

1. From the home page, find and start “PK/PD from scratch”.
2. Explain the difference between clearance, volume and half-life after the
   corresponding chapter and laboratory.
3. Predict a laboratory change, manipulate the highlighted control, interpret
   the curve, write an explanation and answer the application question.
4. Complete one calculation, one guided activity and one synthesis case; ask the
   participant to explain how these formats differ.
5. Find a glossary definition in French, switch to English and open its related
   course or laboratory.
6. Resume a learning path without enabling persistence, then repeat with the
   optional local progress setting enabled.

## Observation measures

- task completion without coaching;
- wrong turns and places where the participant stops;
- time to first meaningful action in a laboratory;
- whether the participant can state the assumption behind the result;
- distinction between educational simulation and clinical recommendation;
- wording, control or navigation changes suggested by more than one profile.

Do not convert these observations into a mastery score. Summarise recurring
problems and create one issue per actionable change.

## Accessibility pass

Repeat the core tasks at 320 px and 200% zoom, with keyboard only and with a
screen reader. Verify:

- visible focus and logical focus order;
- accessible names for controls, plots and canvases;
- no action available only by dragging;
- no text overlap or horizontal page scrolling;
- live values and conclusions available as text or tables;
- colour is not the only carrier of current/reference or correct/incorrect;
- reduced motion leaves all controls and results usable;
- French and English labels announce correctly.

Document browser, device, assistive technology, date, tasks completed and open
issues. Publication must not imply that this protocol was run until dated
evidence exists.
