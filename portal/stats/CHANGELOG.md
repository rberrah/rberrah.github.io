# Stats changelog

## 0.1.0 — 2026-09-27

- Separate presentation (`/stats/`) and analysis (`/stats/tool/`) pages.
- French / English interface.
- Deterministic question-to-test guidance; no LLM method selection.
- Welch, Mann–Whitney, paired t, Wilcoxon, one-way ANOVA, Kruskal–Wallis, chi-square, Fisher exact, Pearson, Spearman and simple linear regression.
- Effect estimates, confidence intervals where supported, p-values, effect sizes, descriptive summaries, assumptions and reporting strings.
- Built-in demo datasets, CSV import for two-column analyses and group/value data, copy and print/PDF actions.
- Browser-only computation: user data are not sent to a statistical backend.
