# PMx Explain — règles de contribution

## Qualification bilingue obligatoire (FR/EN)
Pour toute modification visible : vérifier le sens scientifique, les consignes, les retours correct/incorrect, légendes, unités, nombres, libellés d'accessibilité, liens et mise en page dans les deux langues. Tester chaque fonctionnalité depuis une entrée directe FR et EN (pas seulement une traduction après clic), puis le changement de langue dans les deux sens sans perte de progression ni d'état. Les tests de navigation et de calcul ne prouvent pas seuls la qualité éditoriale : relire les textes FR/EN côte à côte. Ajouter/adapter les tests Playwright concernés pour les deux langues avant fusion ; ne jamais déclarer un contrôle réussi sans résultat. Conserver les validations scientifiques et la qualification de déploiement.

Pour PMx Game, lire `docs/PMX_GAME.md`. Pour le journal éditorial, lire `docs/PMX_NEWS.md`. Les modifications doivent être qualifiées avant fusion et déploiement GitHub Pages. Ne pas contourner les contrôles scientifiques ou navigateur ; signaler les tests intermittents et les limites scientifiques.
