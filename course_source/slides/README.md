# Slide source material

This folder contains the source PowerPoint deck used to reconstruct the visual pharmacometrics course.

Current source:

```text
pharmacometrie_pratique_grenoble.pptx
```

Use this deck as raw pedagogical material only.

Do not serve the PowerPoint directly as the main course experience. Convert its concepts into:

- Markdown chapters in `src/content/chapters/`;
- slide metadata in `src/content/slides/slide_catalog.yaml`;
- static slide PNGs in `static/slides/` when useful;
- reusable Svelte visualizations.

The current repository may already contain exported slides and slide metadata. Before asking Emergent to generate new chapters, ask it to check whether the catalog and exported slide images match this PowerPoint version.
