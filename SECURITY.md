# Security policy

PMx Explain is research and educational software. Do not submit patient data, credentials, unpublished clinical files or other sensitive information in an issue, pull request or test fixture.

## Supported version

Security fixes target the current `main` branch and the currently deployed GitHub Pages release. Historical releases keep their original licences but are not maintained as separate security branches.

## Reporting a vulnerability

Prefer GitHub private vulnerability reporting for this repository when it is available. If that channel is unavailable, use the contact route published at https://rberrah.github.io/contact/ to request a private reporting channel. Do not disclose exploit details or sensitive data in a public issue.

For dependencies, reproducible advisories and proposed upgrades should include the affected package/version, advisory identifier and the PMx execution path that is actually exposed.
